# 🐱 MiAU.exe — Painel de Usuários

Painel interativo da comunidade **MiAU.exe**, desenvolvido para praticar **JavaScript, manipulação do DOM e eventos**, mantendo a identidade visual retrô e pixelada do projeto.

## ✨ Sobre o projeto

O **MiAU.exe — Painel de Usuários** permite cadastrar e gerenciar membros de uma comunidade felina fictícia através de uma interface inspirada em jogos 8-bit.

O projeto trabalha conceitos fundamentais de JavaScript enquanto mantém uma experiência visual divertida e responsiva.

## ⚙️ Funcionalidades

* 👤 Cadastro de usuários com nome, idade e e-mail
* 🔎 Pesquisa de usuários pelo nome
* 🔤 Ordenação da lista em ordem alfabética
* 🗑️ Remoção do último usuário cadastrado
* 🔢 Contador de usuários
* 🎂 Classificação por faixa etária
* 🐱 Mascote interativo com evento `mouseover`
* 💬 Mensagens de status atualizadas dinamicamente
* 📱 Layout responsivo

## 🧠 Conceitos praticados

* Manipulação do DOM
* Eventos com `addEventListener`
* Arrays e objetos
* Arrow Functions
* `if / else if / else`
* `forEach()`
* `filter()`
* `sort()`
* `push()` e `pop()`
* Template Strings

## 🚀 Como executar

1. Clone este repositório:

```bash
git clone [URL_DO_REPOSITORIO](https://github.com/LauraFMP/Responsividade-Fundamentos-de-JavaScript-Gatos)
```

2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

Não é necessário instalar dependências.

## 🎮 Como usar

Preencha o formulário com **nome, idade e e-mail** e clique em `cadastrar +`.

Depois do cadastro, você pode pesquisar usuários pelo nome, ordenar a lista de A–Z ou remover o último usuário cadastrado.

Passe também o mouse sobre o gatinho pixelado para ativar uma interação especial. 🐾

## 🎨 Interface

O projeto utiliza uma estética **retrô/pixel art**, com as fontes **Press Start 2P** e **VT323**, além de uma paleta com tons de rosa, lilás, azul e cores escuras.

O layout utiliza **media queries**, Flexbox e CSS Grid para se adaptar a diferentes tamanhos de tela.

## 🎯 Objetivo

Este projeto foi desenvolvido para praticar os fundamentos de **JavaScript no front-end**, principalmente manipulação do DOM, arrays, objetos, funções e eventos através de uma aplicação interativa.
